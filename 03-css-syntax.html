Sintaxis de CSS

Este párrafo utiliza un selector para aplicar color y alineación desde un archivo CSS externo.

Regla CSS utilizada

p {
    color: red;
    text-align: center;
}

Elementos de la sintaxis

  • Selector: p
  • Propiedad: color
  • Valor: red
  • Propiedad: text-align
  • Valor: center
