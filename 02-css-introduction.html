Introducción a CSS

CSS permite dar estilo a una página web modificando colores, fuentes, alineación, fondos y muchos otros aspectos visuales.

¿Por qué usar CSS?

  • Separa el diseño del contenido.
  • Permite reutilizar estilos en múltiples páginas.
  • Facilita el mantenimiento de un sitio web.
  • Adapta el diseño para distintos dispositivos.

Ejemplo de CSS

body {
    background-color: lightblue;
}

h1 {
    color: white;
    text-align: center;
}

p {
    font-family: Verdana;
    font-size: 20px;
}
